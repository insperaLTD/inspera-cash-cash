# Inspera Cashflow

אפליקציית Node.js ו-Express לניהול תזרים מזומנים, עם PostgreSQL וממשק אינטרנטי.

נדרשים Node.js 18 ומעלה ו-PostgreSQL. כדי להפעיל מקומית, העתיקו את `.env.example` ל-`.env`, הגדירו את משתני הסביבה, הריצו את `src/db/schema.sql` במסד, ואז:

```bash
npm install
npm start
```

הוראות מפורטות להעלאה ל-GitHub ולפריסה ב-Railway נמצאות ב-[DEPLOY.md](./DEPLOY.md).
